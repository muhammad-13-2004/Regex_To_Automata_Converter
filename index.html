Regular Expression:

(g + ggg + gg)* mm + hg + ggh

Regex to Automata Converter

A powerful web-based simulator that converts any Regular Expression into an NFA (using Thompson's Construction), then transforms it into a DFA (via Subset Construction), and finally produces the Minimized DFA using Myhill Nerode Theorem.

  • ✨ Step-by-step visualization of Thompson's Construction
  • 🔄 Interactive NFA → DFA conversion
  • 🗜️ DFA Minimization with clear state partitioning
  • 🎨 Beautiful state diagrams.
